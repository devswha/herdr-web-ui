### Fixed
- Closing the file panel beside the pane with Close file or Escape returns the focus to the link
  or row that opened the file, as closing the popup does.
- Selecting another pane or PC while a file is open beside the pane closes the file, and Back
  returns to the pane it was open on without reopening it.
- Two quick clicks on Show beside the pane (or a text file's automatic move at the same moment)
  no longer step back twice through the history and open the file twice.
