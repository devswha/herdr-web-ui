### Removed
- Eleven settings, each now fixed at what most devices already used: Contrast, Text smoothing,
  Panel motion, Interface font and Code font (built-in fonts), Show pace for the plan meters (off),
  the Suggestion chip and Folder and branch switches (always shown), Fit 80 columns in a split
  pane (always on), and the terminal's Cursor shape and Blinking cursor (a blinking block). A
  program in a pane can still change its cursor, and the system's reduced-motion setting still
  turns animations off.
